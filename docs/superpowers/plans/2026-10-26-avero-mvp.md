# AVERO MVP — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** construire le MVP d'AVERO, avec un espace créateur (KPI Instagram/TikTok) et un espace marque (KPI des créateurs filtrés selon le plan FREE/BASIC/PREMIUM).

**Architecture :** une application Next.js unique. Les pages lisent toutes les données via `src/lib/data/`. En **Phase A (interface)**, ces fonctions renvoient des données fictives et la session est simulée par un cookie de démo. En **Phase B (backend)**, on les remplace par Prisma/Supabase, Better Auth et la vraie connexion OAuth aux réseaux, sans réécrire les pages. Le calcul des KPI (`kpi.ts`) et le filtrage par plan (`plans.ts`, `creator-query.ts`) sont des fonctions pures, partagées par les deux phases.

**Tech Stack :** Next.js 16.4.3 (App Router), TypeScript, Tailwind CSS, GSAP (ScrollTrigger, SplitText, @gsap/react), Lenis, Recharts, Vitest, Prisma, Supabase (PostgreSQL), Better Auth, pnpm.

**Spec :** `docs/superpowers/specs/2026-10-26-avero-mvp-design.md`

## Global Constraints

- Next.js **16.4.3** exactement (`next@16.4.3`). Dans Next 16 : le fichier `src/proxy.ts` (fonction `proxy`) remplace `middleware.ts` ; `params`, `searchParams` et `cookies()` sont asynchrones (`await`).
- Gestionnaire de paquets : **pnpm**. Commandes : `pnpm run dev`, `pnpm run build`, `pnpm test`.
- Interface **100 % en français**. Le code (noms de variables et de fonctions) est en anglais.
- **Aucun secret dans le code ni dans git** : tout passe par `.env` (ignoré par git). `.env.example` liste les noms sans valeurs.
- Rôles : `"CREATOR" | "BRAND"`. Plans : `"FREE" | "BASIC" | "PREMIUM"`. Réseaux : `"INSTAGRAM" | "TIKTOK"`.
- Fenêtre KPI : publications dont `publishedAt >= now - 30 jours`.
- Les données réservées à un plan supérieur ne quittent **jamais** le serveur (les champs sont retirés avant d'être envoyés à la page).
- L'utilisateur ne sait pas coder (CLAUDE.md) : à chaque tâche, expliquer simplement ce qui est fait et pourquoi. Messages de commit **en français**. Depuis le 2026-10-28, l'utilisateur autorise un commit par tâche terminée sans redemander.
- `pnpm run build` et `pnpm test` doivent réussir avant chaque commit.
- Next 16 (`cacheComponents` + `partialPrefetching` activés) : lire `params`/`searchParams` dans un composant enfant placé sous `<Suspense>` ; une page qui lit la session (cookies) est couverte par un `loading.tsx` ; tout composant de l'en-tête qui lit la session est sous `<Suspense>`.
- Animations : GSAP via `useGSAP` (`@gsap/react`), uniquement sur `transform` et `opacity`. Tout passe par `gsap.matchMedia()` avec la condition `(prefers-reduced-motion: no-preference)` : sans elle, le contenu s'affiche directement. Le contenu reste lisible si JavaScript ne s'exécute pas (l'état caché n'est appliqué que par GSAP).
- Direction artistique : jetons de la spec, section 3.2, définis une seule fois dans `globals.css` (`@theme`).

## Review Focus

1. **Marque FREE qui bricole l'URL** (`/marque?sort=engagementRate&platform=TIKTOK`, `/marque/createurs/c1`, `/marque/export`) → tri ramené à `views30d`, filtres ignorés, encart d'incitation au lieu des données, réponse 403 pour l'export. *Tests : Tâches A4 et A11.*
2. **Créateur sans publication sur 30 jours ou avec un seul relevé d'abonnés** → « — » ou « Données insuffisantes », jamais `NaN` ni `Infinity`. *Tests : Tâche A2.*
3. **Inscription avec un rôle trafiqué** (`role: "ADMIN"` ou absent) → inscription refusée. *Tests : Tâche B2.*
4. **Retour OAuth anormal** (`?error=access_denied`, `state` absent ou différent du cookie) → aucune connexion créée, message affiché. *Tests : Tâche B6.*
5. **Jeton révoqué ou expiré pendant une actualisation** → la connexion passe en `EXPIRED`, les anciennes données restent, bandeau « Reconnecte ton compte ». *Tests : Tâches B4, B5 et B6.*
